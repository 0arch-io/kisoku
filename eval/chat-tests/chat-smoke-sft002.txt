```python
def is_prime(n):
    if n < 2:
        return False
    for i in range(2, int(n ** 0.5) + 1):
        if n % i == 0:
            return False
    return True
```

This function works by checking divisibility up to the square root of `n`, as any factor larger than that would have a corresponding factor smaller than the square root. This optimization significantly reduces the number of iterations. 

You can use this function like this:

```python
print(is_prime(25))  # False
print(is_prime(23))  # True
```
